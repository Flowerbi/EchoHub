# :book: EchoHub 

**EchoHub** — это веб приложение на Laravel, созданное для публикации и просмотра постов пользователей. Проект включает систему регистрации и авторизации, роли пользователей, комментарии к постам и личный кабинет.

#### Возможности
- Регистрация и авторизация пользователей.
- Выбор роли при регистрации: админ или пользователь.
- Админ может создавать и просматривать посты, писать комментарии.
- Пользователь может только просматривать посты, писать комментарии.
- Просмотр постов всех пользователей.
- Возможность писать комментарии под каждым постом.
- Личный кабинет с информацией об аккаунте.
- Просмотр всех комментариев, оставленных пользователем.

#### О проекте
Этот проект был разработан как учебное приложение (пет проект) для практики Laravel, работы с маршрутами, контроллерами, моделями, авторизацией, ролями пользователей и связями между сущностями.
Проект был сделан без использования CSS библиотек, все стили писались вручную.

Версии технологий:
- Laravel 13
- PHP 8.3

### :green_circle: Запуск проекта 

После скачивания проекта, установите composer в проект
> composer install

Далее создайте файл .env из .env.example и в нём настройте подключение к Базе данных

Затем добавьте ключ шифрования

>php artisan key:generate

Запускаем миграции в Базу данных
> php artisan migrate

Далее запускаем сид, для заполнения тестовыми данными таблиц в Базе данных
> php artisan db:seed

Запускаем сервер
> php artisan serve
